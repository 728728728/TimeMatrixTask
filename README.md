# Eisenhower Matrix Hub — PDCA戦略＆絶対保存タスク管理

緊急度×重要度の2軸（アイゼンハワーマトリクス）でやることを整理し、「朝に決めて、夜に振り返る」を毎日回すためのタスク管理ツールです。

## 起動のしかた

**`start-matrix-hub.bat` をダブルクリック**するだけで、次の3つがまとめて立ち上がります（すでに動いているものはそのまま使います）。

1. **ローカルサーバー**（`server.py`）— `tasks_data.json` の読み書きを担当
2. **デスクトップの小窓**（`today_widget.pyw`）
3. **ブラウザ**（http://127.0.0.1:8730/）

サーバー経由で開くと、**起動した時点でデータを読み込み、変更は自動で保存**されます。毎回「フォルダ連携」をやり直す必要はありません。

（`index.html` を直接開いた場合は従来どおりで、ファイル連携の操作が必要になります。）

### 自動で立ち上げる（任意）

`setup-autostart.bat` を一度実行すると、次の3つが Windows のタスクとして登録されます。

| いつ | 何が起きるか |
|---|---|
| 毎朝 9:30 | サーバー＋小窓＋ブラウザが開く（朝の確認） |
| 毎日 16:30 | 同上（夜の振り返り） |
| パソコンのログオン時 | サーバーと小窓だけ裏で立ち上がる（ブラウザは開かない） |

やめたいときは `remove-autostart.bat` を実行してください。設定はタスクスケジューラの「TimeMatrixTask ...」から個別に止めることもできます。

## 毎日の使い方

1. **思いついたら入力** — 「今日」タブの入力欄に書いて Enter。複数行を貼り付けると1行ずつ追加されます（`- ` や `・` などの記号は自動で除去）。領域はあとで決めてOK
2. **朝の確認** — ①未仕分けを I〜IV のボタンで仕分け ②候補から「＋今日」で今日やることを選ぶ ③今日いちばん大事なことを1行書く
3. **日中** — ヘッダーのリストボタン（または **D** キー）で、今日のリストだけの小窓を開け閉め。終わったらその場に出る欄に「次にやること」を書けば、そのまま今日のリストに入ります
4. **夜の振り返り** — 残ったものを「明日へ」か「外す」に振り分け、一言ふりかえりを書いて完了

朝と夜の確認は「これまでの記録」に残り、続けた日数が表示されます。深夜4時までは前の日として扱います。

## 主な機能

- **今日**: クイック追加・朝の確認・今日やることリスト・夜の振り返り（起動時の画面）
- **今日やることの小窓**: ヘッダーのリストボタンか **D** キーで、今日のリストだけを別ウィンドウに開けます（もう一度押すか小窓の ✕ で閉じる）。Chrome / Edge なら他のアプリの上に常に表示されます。チェック・追加・「＋次」がその場ででき、配色も本体と揃います
- **ページ内パネル（任意）**: 常に出しておきたい場合は、メニュー（⋮）の「ページ内にもパネルを出す」で画面右上に常時表示できます（既定は非表示）
- **次にやることの追記**: タスクを完了すると「次にやること」欄が開き、Enter で今日のリストに追加されます（領域・カテゴリーは元のタスクを引き継ぎ、つながりが ↓ で表示されます）
- **期限のお知らせ**: デスクトップの小窓が、締め切りの **60分前、30分前、10分前、時間ちょうど、過ぎたとき** に1回ずつ知らせます（Windowsの通知＋音＋小窓を前面に出す）。また、今日のリストに入っていなくても期限が24時間以内のタスクは「⏰ 期限が近いもの」として一覧の下に出、「今日」で引き入れられます
- **2軸マトリックス・グラフ**: タスクをドラッグして緊急度・重要度を調整（タッチ操作対応）
- **4象限カンバンボード**: 領域ごとに整理。列の下の入力欄から直接追加、カードのドラッグで領域を移動
- **アナリティクス**: 領域別のタスク配分とアドバイスを表示
- **色の変更**: ヘッダーのパレットボタンから、8種類のプリセット（ライト系を含む）を選んだり、背景・ガラスの色味・文字・アクセント・各領域の色を自由に変えたりできます。ガラスの透け感とぼかしはどの配色でも同じです。設定はブラウザに保存され、ファイル連携中は `tasks_data.json` にも保存されます
- **作戦メモ・ふりかえり（任意）**: 大事なタスクには「どうやればうまくいくか」「完了の目安」などを残せます。必須ではありません
- **多重バックアップ**: LocalStorage / SessionStorage / 履歴スナップショット / 手動JSON書き出しによるデータ保護
- **ローカルファイル直接同期**: File System Access API を使い、`tasks_data.json` と直接読み書き同期が可能（対応ブラウザのみ）。一度連携すれば次回起動時に自動で再接続します。ファイルにはタスクと日々の記録が `{ "tasks": [...], "days": {...} }` 形式で保存されます（旧形式の配列ファイルもそのまま読み込めます）

## デスクトップ常駐ウィジェット（today_widget.pyw）

ブラウザとは無関係に常駐し、**他のアプリやサイトを見ていても常に最前面に出る**小窓です。Python の標準機能（tkinter）だけで動くので、追加のインストールは不要です。

- 起動: `start-today-widget.bat` をダブルクリック
- できること: 今日のタスクの確認・チェック・追加・「＋次」で次にやることの追記
- 見出しをクリックでたたむ / `―` でタスクバーへ / `✕` で終了。右クリックで「最前面の固定を切り替え」もできます
- 位置と大きさ、たたんだ状態は `.widget_state.json` に覚えます
- 配色はアプリ本体で選んだテーマをそのまま使います

### ブラウザとの同期

どちらも同じ `tasks_data.json` を読み書きします。ウィジェットは2秒ごとにファイルの更新を見ており、ブラウザ側も外部の変更を検知して取り込みます。書き込みは「読み直してから変更を足して一気に差し替える」方式で、直前の内容を `tasks_data.json.bak` に1世代残します。

※ `start-matrix-hub.bat` から開いていれば、ブラウザ側の連携操作は不要です。`index.html` を直接開いた場合のみ、「フォルダ連携」で `tasks_data.json` を選ぶ必要があります。

git clone https://github.com/728728728/TimeMatrixTask.git

## 注意

`tasks_data.json`（実際のタスクデータ）は個人情報保護のため `.gitignore` で除外されています。初回起動時はデータが空の状態から始まります（メニューの「サンプルデータ投入」で動作確認可能）。
