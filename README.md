# Eisenhower Matrix Hub — PDCA戦略＆絶対保存タスク管理

緊急度×重要度の2軸（アイゼンハワーマトリクス）でやることを整理し、「朝に決めて、夜に振り返る」を毎日回すためのタスク管理ツールです。

## 毎日の使い方

1. **思いついたら入力** — 「今日」タブの入力欄に書いて Enter。複数行を貼り付けると1行ずつ追加されます（`- ` や `・` などの記号は自動で除去）。領域はあとで決めてOK
2. **朝の確認** — ①未仕分けを I〜IV のボタンで仕分け ②候補から「＋今日」で今日やることを選ぶ ③今日いちばん大事なことを1行書く
3. **日中** — 「今日やること」のチェックで完了
4. **夜の振り返り** — 残ったものを「明日へ」か「外す」に振り分け、一言ふりかえりを書いて完了

朝と夜の確認は「これまでの記録」に残り、続けた日数が表示されます。深夜4時までは前の日として扱います。

## 主な機能

- **今日**: クイック追加・朝の確認・今日やることリスト・夜の振り返り（起動時の画面）
- **2軸マトリックス・グラフ**: タスクをドラッグして緊急度・重要度を調整（タッチ操作対応）
- **4象限カンバンボード**: 領域ごとに整理。列の下の入力欄から直接追加、カードのドラッグで領域を移動
- **アナリティクス**: 領域別のタスク配分とアドバイスを表示
- **作戦メモ・ふりかえり（任意）**: 大事なタスクには「どうやればうまくいくか」「完了の目安」などを残せます。必須ではありません
- **多重バックアップ**: LocalStorage / SessionStorage / 履歴スナップショット / 手動JSON書き出しによるデータ保護
- **ローカルファイル直接同期**: File System Access API を使い、`tasks_data.json` と直接読み書き同期が可能（対応ブラウザのみ）。一度連携すれば次回起動時に自動で再接続します。ファイルにはタスクと日々の記録が `{ "tasks": [...], "days": {...} }` 形式で保存されます（旧形式の配列ファイルもそのまま読み込めます）

## 技術構成

- Vanilla JavaScript / HTML / CSS（フレームワーク不使用）
- [Font Awesome](https://fontawesome.com/)（CDN）、Google Fonts（CDN）

## 使い方

1. このリポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く

```bash
git clone https://github.com/728728728/TimeMatrixTask.git
```

## 注意

`tasks_data.json`（実際のタスクデータ）は個人情報保護のため `.gitignore` で除外されています。初回起動時はデータが空の状態から始まります（メニューの「サンプルデータ投入」で動作確認可能）。
